# Client logo sources

All files taken from each organisation's own official website on 2 Nov 2026 (SAST). No third-party logo sites used. No redrawing. The only treatment is a uniform CSS monochrome filter (`grayscale(1) brightness(0)`, 60% opacity) on the strip, plus cropping, resizing and webp/svgo optimisation.

**Permission:** using a client's logo implies endorsement. Each client's written permission is needed before this goes live.
